## The problem

I wanted a personal AI setup that actually runs day-to-day, not a demo I babysit.
That meant several specialized bots (not one giant prompt), working API access even
when a provider has a billing hiccup, and data hygiene so storage doesn't grow forever.

## What I built

Agento orchestrates six AI agents — one master coordinator plus five domain bots —
on Discord through a single multiplexed gateway process. Each agent gets an isolated
profile home, workspace, and per-profile credential scope, so a misbehaving bot can't
wander into another's context.

The piece I'm proudest of is the credit-aware LLM proxy: it routes chat completions
to OpenCode Zen and automatically falls back to DeepInfra on credit or payment errors,
with private SearXNG search alongside. The system degrades instead of dying.

## How it runs

Everything is Docker Compose: search, proxy, health API, gateway, dashboard, and a
retention job. Dev mode targets a `test_` database on the remote cluster, so
development never touches production data. A Health Connect pipeline syncs daily
activity, sleep, and workouts from an Android app into FastAPI + MongoDB, with
summaries posted back to Discord. Scheduled jobs enforce the lifecycle — 90-day
transaction wipes, 30-day health-data pruning — and the dashboard and APIs sit behind
Tailscale, firewall rules, and password auth.

## What it taught me

Reliability is a feature you design for: fallback chains, isolated credentials, and
automated cleanup matter more than model choice. Most of this system exists so that
nothing pages me.
