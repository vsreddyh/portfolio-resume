## What it does

Orchestrates six AI agents (one master coordinator + five domain bots) on Discord through a single multiplexed gateway process. Each agent gets an isolated profile home, workspace, and per-profile credential scope.

## Key engineering

- **Credit-aware LLM proxy:** routes chat completions to OpenCode Zen, automatically falling back to DeepInfra on credit/payment errors, alongside private SearXNG search.
- **Compose-native ops:** search, proxy, health-api, gateway, dashboard, and retention job all run on Docker Compose. Dev mode targets a `test_` database on the remote cluster so development never touches production.
- **Health Connect pipeline:** an Android app syncs daily activity, sleep, and workout data to a FastAPI service that persists it in MongoDB and posts summaries to Discord.
- **Lifecycle + security:** scheduled retention jobs (90-day transaction wipes, 30-day health-data pruning); dashboard and APIs secured behind Tailscale, firewall rules, and password auth.
