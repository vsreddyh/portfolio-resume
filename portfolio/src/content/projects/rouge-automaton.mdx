## What it does

Serves game intel through a direct gateway plus an OpenCode relay client, backed by a MongoDB store with keyword retrieval and cited context.

## Key engineering

- Wiki ingestion pipeline: RecentChanges polling, wikitext parsers, live war-status feed; falls back to live wiki lookup with source links on local misses.
- Multi-service Podman Compose deployment (bot, watcher, Mongo) from a distroless image.
- Standalone MCP server over the shared tool executor; Go tests across packages; one-shot ingest seeding MongoDB from checked-in JSON intel.
