## What it does

Uploads hit MinIO for fast, bursty ingest. A nightly mirror syncs to S3 and purges MinIO; access is short-lived via signed S3 URLs.

## Key engineering

- Curated-only retention in S3 (about 10–25% fewer request charges by cutting noisy request overhead).
- FastAPI backend issuing presigned URLs; image list in MongoDB; Redis-cached signed URLs to cut repeat-access latency.
- Docker Compose across Bun/Vite frontend, FastAPI backend, MongoDB, Redis, and MinIO.
