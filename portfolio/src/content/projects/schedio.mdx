## What it does

Connects students, colleges, and recruiters for project discovery and collaboration, with role-based access control and profile management.

## Key engineering

- Scraped data from over 10,000 colleges to build an institutional dataset.
- Tokenized search and filtering, plagiarism detection, and AI-powered code explanations via the Gemini API.
- File uploads (code, images, videos), analytics, PDF exports, and contributor management.
- Docker for dev/production parity; live deployment on Vercel.
