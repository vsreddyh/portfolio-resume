## What it does

Self-hostable, scalable attendance system using Python and the `face_recognition` library, reported at 99.38% identification accuracy in the resume's evaluation.

## Key engineering

- Web portal for attendance records with batch-wise and class-wise organization, plus a student dashboard for checking status.
- Linux ElectronJS app with a custom-built virtual keyboard for touchscreen devices.
