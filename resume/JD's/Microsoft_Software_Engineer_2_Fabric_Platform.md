## Overview

Microsoft's Azure Data engineering team is leading the transformation of analytics in the world of data with products like databases, data integration, big data analytics, messaging & real-time analytics, and business intelligence. Products include Microsoft Fabric, Azure SQL DB, Azure Cosmos DB, Azure PostgreSQL, Azure Data Factory, Azure Synapse Analytics, Azure Service Bus, Azure Event Grid, and Power BI. Mission: build the data platform for the age of AI.

Within Microsoft Fabric, the Platform team builds and operates the unified foundation that brings together all Fabric workloads into a single, cohesive experience — shared infrastructure, governance, security, and a unified data model.
