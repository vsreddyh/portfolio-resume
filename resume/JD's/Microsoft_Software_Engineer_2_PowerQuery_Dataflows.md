## Overview

Microsoft's Azure Data engineering team is leading the transformation of analytics with Microsoft Fabric, Azure SQL DB, Cosmos DB, PostgreSQL, Data Factory, Synapse, Service Bus, Event Grid, and Power BI. Mission: build the data platform for the age of AI.

Within Microsoft Fabric, the Data Integration team enables organizations to connect, move, and shape data across their entire data estate: ingest, transform, and prepare data for analytics, real-time insights, and AI scenarios. The team is hiring a Software Engineer II to work on Power Query and Dataflows, focusing on:

- End-to-End Data Integration: solutions that let customers connect, transform, and integrate data seamlessly, from no-code experiences to complex enterprise scenarios.
- High-Scale Engineering: high-throughput, multi-tenant services with strong reliability, scalability, and maintainability.
- Customer-Centric Innovation: product functionality, performance, and usability across Microsoft surfaces like Fabric, Excel, and Power Platform.
